# Python Mastery

A curated collection of clean, well-documented Python projects demonstrating core programming concepts.

## Projects

### Shopping Cart System
Full-featured console-based shopping cart with stock management and bill generation.

### Quiz Application
Interactive quiz app with JSON-based question bank and score tracking.

### Electricity Bill Calculator
Pakistan K-Electric tariff calculator with slab-based billing.

### ATM Simulator
Console-based banking simulator with account management.

### Weather Agent
AI-style weather agent using Open-Meteo APIs.

### Birthday Usman
A cinematic birthday experience with procedural tree growth.

### httpx Weather Agent
An HTTP client-based weather agent using httpx for async API calls.

### Wedding Invitation Generator (FastAPI)
A modern wedding invitation generator with 4 Pakistani wedding themes.

## Tech Stack
- Python 3.10+
- FastAPI + Uvicorn
- Supabase (PostgreSQL + Auth)
- Jinja2 Templates
- Tailwind CSS (CDN)

## Getting Started
git clone https://github.com/SaadRiaz99/Python-Mastery.git
cd Python-Mastery
pip install -r requirements.txt
cp .env.example .env
python main.py
