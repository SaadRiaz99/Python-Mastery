E-Commerce Data Analytics & Machine Learning
About the Project

This project focuses on analyzing an e-commerce business using Python, NumPy, Pandas, Data Visualization, and Machine Learning.

The goal is to understand customer purchasing behavior, analyze sales performance, identify business trends, and eventually build machine learning models.

Technologies Used
Python
NumPy
Pandas
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
