# Hints — read only when stuck

Use one hint at a time.

1. Print `type(first)` and `type(second)`.
2. Test the exact boundary value separately.
3. Check what the stop value of `range()` includes.
4. Inspect both the percentage formula and the function's returned value.
5. Compare the dictionary key you read with the student you intend to update.
6. A bare `except` catches much more than invalid integer input.
7. Build the path from `Path(__file__)` and ensure the parent directory exists.
8. Mutable class attributes are shared by every instance.
9. A directly executed file has a special `__name__` value.
10. `dict.get()` supports a default.
11. The wrapper calls the function but discards something important.
12. A generator uses `yield`, and a loop must be allowed to continue.
13. `asyncio.gather()` can resolve several coroutine objects.
14. Parentheses decide which part is multiplied.
15. Check shared state, quantity validation, multiplication by quantity, and percentage math.
