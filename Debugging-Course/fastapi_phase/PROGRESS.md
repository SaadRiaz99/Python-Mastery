## Status meanings

- **Not started:** Original failure not reproduced.
- **Attempted:** Evidence recorded, fix incomplete.
- **Partial:** Main case works, edge case fails or explanation is weak.
- **Completed:** Requirement preserved, tests pass and root cause explained.
- **Retry:** Test/requirement changed or bug hidden instead of fixed.
