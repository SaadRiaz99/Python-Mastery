# AI Coding Prompt: Modern Pakistani Wedding Invitation Generator

Build a modern, elegant, and professional web application for creating and sending **personalized Pakistani-style wedding invitations online**.

The application should allow the admin to create a wedding invitation, upload a CSV file containing invited members, and automatically generate a personalized invitation link for each person.

## CSV File Format

The CSV file will contain only two columns:

```csv
name,contact
Muhammad Riaz,+923001234567
Farzana Perveen,+923111234567
Saad Riaz,+923221234567
```

### Requirements

* `name` is required.
* `contact` is required.
* Validate the CSV file before importing.
* Show an error if required columns are missing.
* Prevent duplicate contacts.
* Display uploaded guests in a professional table.
* Allow the admin to delete individual guests.

---

## Unique Invitation Link

Automatically generate a unique link for every guest.

Example:

```text
https://your-domain.com/invite/a8f4c2b9
```

When the guest opens the link, the application should identify them and display:

```text
Dear Muhammad Riaz,
```

The invitation should be personalized using their name from the CSV file.

---
